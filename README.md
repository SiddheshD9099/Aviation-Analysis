# ✈️ Airline Passenger Analysis Dashboard | Excel

## 📌 Project Overview

The **Airline Passenger Analysis Dashboard** is an Excel-based data analytics project designed to analyze airline passenger data and present meaningful insights through KPI summaries, charts, and structured reports.

The project focuses on exploring passenger demographics, flight status distribution, departure patterns, and airport-related information. It transforms raw data into an organized dashboard that makes information easier to understand and interpret.

## 🎯 Project Objectives

- Analyze airline passenger records to identify patterns and distributions.
- Understand flight status categories and their proportions.
- Explore passenger demographics such as age and gender.
- Analyze departure patterns across different time periods.
- Examine airport country and continent-related distributions.
- Build a dashboard to present key metrics in a clear and structured format.

## ⚠️ Limitations

- The dataset provides flight status categories but does not necessarily contain actual delay durations.
- The analysis does not establish the root causes of delays.
- Passenger-level records should not automatically be interpreted as unique flights.
- Findings are limited to the fields available in the dataset.
